# SECURITY.md

If you believe you have found a security vulnerability in the Loopable Instance Server, report it privately.

Do not open a public issue or PR for an undisclosed vulnerability.

Report vulnerabilities by emailing the Loopable Foundation at `security@loopable.party`.

Include:

- a description of the vulnerability
- the affected protocol version or section
- steps to reproduce, if applicable
- the potential impact

Security issues affecting independent implementations may also be reported here. (using GitHub's Vulnerability Reporting)
