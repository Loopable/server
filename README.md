# Loopable Instance Server
This repository contains the Loopable Instance Server. It is used for self-hosting Loopable instances; for more information on setting up your own, please see https://docs.loopable.party

New to Loopable, or want to learn more? See https://loopable.party for more information.

## For contributors
If you wish to contribute, please see `CONTRIBUTING.md`.

### For Agents
If you are an agent, please see both `AGENTS.md` and `CONTRIBUTING.md`.
